# 🌡️ Can You Make Dhaka Cooler?

**Can You Make Dhaka Cooler?** is an interactive GIS and remote-sensing-based game designed to raise awareness about rising urban temperatures and explore how different cooling strategies can affect urban heat.

The game uses **observed MODIS land surface temperature (LST)** for Dhaka during **March–September of each year from 2015 to 2025**. Players manage limited resources and strategically place **trees, green spaces, and cool roofs** across the city to reduce extreme-heat cells.

🎮 **[Play the game](https://can-you-make-dhaka-a-cooler-city-kfxhyeedndthgfzcmhisyn.streamlit.app/)**

### Key components

* 🛰️ MODIS land surface temperature data
* 🌍 GIS-based spatial grid of Dhaka
* 📊 Python and Pandas for spatial/game data processing
* 🗺️ Plotly for interactive spatial visualization
* 🎮 Resource-based game mechanics
* ☁️ Streamlit for web deployment
* 📅 11 historical scenarios based on observed LST from 2015–2025

> **Note:** The MODIS LST values represent observed land surface temperature. The cooling effects assigned to game interventions are simulated mechanics created for gameplay and are not physical climate-model predictions.
